# 并语 BINGYU

一个只做 AI 网页工作台的 Windows 客户端。原生 WPF 界面，使用系统 Microsoft Edge WebView2，不随应用捆绑 Chromium 浏览器。

## 打开应用

从 GitHub Releases 下载其中一个 Windows x64 压缩包，解压到普通文件夹后双击 `Bingyu.exe`。快速上手见 [QUICKSTART.md](QUICKSTART.md)。

- `Bingyu-win-x64.zip`：轻量版，另需安装 .NET 10 Desktop Runtime。
- `Bingyu-win-x64-self-contained.zip`：自带 .NET，适合新电脑直接使用，压缩包较大。

两个版本都使用系统的 Microsoft Edge WebView2 Runtime，不需要管理员权限运行应用本身。

需要 **Windows 10/11 x64 和 Microsoft Edge WebView2 Evergreen Runtime**。轻量版还需要 **.NET 10 Desktop Runtime**。单独复制到其他电脑时，如提示缺少组件，请从微软安装：

- [.NET 10 Desktop Runtime（选择 Windows x64）](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)
- [Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)

轻量版不捆绑 .NET 和浏览器运行时，因此体积较小；第三方网页的内存和联网时间仍取决于网站内容、打开数量及网络。客户端也可以构建包含 .NET 的版本，但安装包会明显变大。

## 日常使用

- 在首页或左侧栏点击工具，打开或切换到已有页面。内置 ChatGPT、Claude、Gemini、DeepSeek、豆包、千问和智谱清言。
- **Ctrl + 点击工具**，或右键选择「新开一个」，为同一网站新建独立页面。页面共用本站的登录状态。`Ctrl+D` 也可为当前工具新开一页。
- 顶部视图按钮切换 **1 / 2 / 3 / 4 屏**。3 屏采用左侧主屏、右侧上下分屏，4 屏采用 2×2 布局。**按住屏幕之间的灰色短线拖动**，即可调整宽高比例；每种布局分别保存比例。
- 点击任一屏的网页内容即可选中该屏；Ctrl+L、F5、F11、Ctrl+D 等快捷键会作用于选中的页面。切换标签会在当前屏显示，已经显示在另一屏的标签会直接聚焦到原屏。
- 页面工具栏的放大按钮可单屏放大；再次点击或按 Escape 还原。
- 点击页面工具栏「专注」，或按 F11，可单独隐藏该标签所在屏的标题和浏览器工具栏。网页四周保留一圈细边距，避免内容贴住应用边界。再次按 F11 或右键标签退出；每个标签独立记住状态。专注时按 Ctrl+L 会显示地址栏。
- 点击左侧栏底部的顶栏按钮或按 F10，可隐藏或显示应用的标题栏与标签栏。隐藏后可拖动左侧栏顶部的窄条移动窗口，此状态会在重启后恢复。
- 默认开启内存节省：切到别的标签或隐藏并语后，后台网页会立即暂停；持续隐藏 60 秒后释放对应的 WebView2 渲染器。再次切回会按原网址重新载入，并继续使用原有登录状态。网页中尚未提交的文字可能丢失，可在设置中关闭这项功能。页面月亮按钮或标签右键菜单仍可手动休眠并尽量保留当前页面状态。
- 左侧「＋」添加自定义网站。右键自定义工具可移除入口，已打开的页面仍保留。
- 右键左侧任意工具选择「更换图标…」，可使用本地 PNG、JPG、ICO 或 BMP；也可恢复默认图标。图片缩小后保存在本机。
- 每屏都有后退、前进、刷新和地址栏；页面菜单支持复制网址、重置缩放、在默认浏览器打开。
- 在网页中的链接上右键，可选择「在默认浏览器中打开链接」。网页发起下载时会弹出系统“另存为”窗口，可保存 AI 生成的 Markdown、图片等文件。
- 七个内置工具使用各自官网提供的图标。Gemini 默认在较窄的分屏中自动调整网页缩放：宽度低于 820 像素或高度低于 660 像素时为 90%，宽度低于 550 像素或高度低于 480 像素时为 80%。因此拖动分隔线跨过这些尺寸会看到字号跳变。页面菜单可选择「固定 100% / 90% / 80%」，固定后拖动不再改变网页缩放，并会记住设置；网站自身仍可能随宽度重新排版。
- 默认按 **Alt+Space** 隐藏或唤出，在设置中可以修改。若被其他程序占用，顶栏会短暂提示并可更换。
- 关闭窗口默认保留在托盘。**彻底退出：右键系统托盘图标 → 退出并语。**再次启动同一个程序会唤出已有窗口。

| 快捷键 | 操作 |
| --- | --- |
| Alt+Space（可修改） | 全局显示 / 隐藏 |
| Ctrl+T | 工具首页，选择新页面 |
| Ctrl+W | 关闭当前页面 |
| Ctrl+D | 同一工具新开页面 |
| Ctrl+Tab / Ctrl+Shift+Tab | 切换页面 |
| Ctrl+L | 聚焦当前屏的地址栏 |
| F5 | 刷新当前网页 |
| F10 | 隐藏 / 显示应用顶栏 |
| F11 | 切换当前标签的专注模式 |
| Ctrl+Alt+1 / 2 / 3 / 4 | 切换分屏布局 |
| Escape | 退出单屏放大 |
| Ctrl+, | 偏好设置 |

## 登录与兼容性

通过各网站自己的登录界面登录，不需要 API Key，也不会把 API 计费接入到应用。所有页面共用本应用的 WebView2 用户数据目录；Cookie 按网站域隔离，同站多开共享账号，不同网站仍各自登录。

登录弹窗使用同一浏览器环境并保留 `window.opener`，支持依赖弹窗的正常授权流程。**并非所有平台都允许嵌入式浏览器登录**：个别登录方式可能受 Google 等身份提供商策略、验证码、地区或网络限制。应用不绕过这些限制。可以尝试平台官方支持的其他登录方式，或在默认浏览器使用；默认浏览器的登录不会自动同步回来。

第三方服务没有 API 级集成，也没有注入或修改网站页面。语音和文件上传使用 WebView2 与网站原有能力；网页下载由系统“另存为”窗口选择保存位置。网站通知默认允许并记住，麦克风、摄像头、位置等权限由用户决定，选择也会记住。外部协议启动、浏览器扩展和依赖外部客户端回调的登录流程暂不支持。

## 本地数据

新安装的数据保存在 `%LOCALAPPDATA%\Bingyu\`。如果电脑上已有旧版数据目录 `%LOCALAPPDATA%\Qiye\`，并语会继续使用它，保留登录和配置：

- `settings.json`：工具、网址、页面、分屏比例和偏好；保存失败会提示，并保留上一版 `.bak`。
- `Icons\`：用户自定义的网站图标。
- `WebView2\`：浏览器 Cookie、缓存、站点数据和登录状态。
- `errors.log`：仅本地异常日志，出现错误时创建。

应用没有自己的后端，不主动发送遥测。所打开的网站按其各自规则联网。浏览器数据属于隐私数据，不要把这个目录提交或分享。退出后删除该目录会清除应用配置和所有登录状态。

启动会恢复页面记录，但只初始化当前显示的页面。未显示过的后台标签按需创建，从而减少初次启动的开销。正在 2 / 3 / 4 分屏中同时显示的网页各自需要一个 WebView2 渲染器；它们都属于活跃页面，因此实际内存仍取决于网站本身，三个复杂 AI 网页同时显示时不会降到普通原生页面的水平。

## 构建和检查

使用 .NET 10 SDK，在此目录运行：

```powershell
dotnet run --project tests/Bingyu.Core.Tests -c Release
dotnet run --project src/Bingyu.App -c Release
.\scripts\Test-Desktop.ps1
.\scripts\Build.ps1
```

`Build.ps1` 先执行核心测试，再发布 Windows x64 单文件轻量版并打包。需要包含 .NET 的版本时使用 `Build.ps1 -SelfContained`；仍使用系统 WebView2。

桌面集成测试使用隔离数据目录和本地 HTTP 测试网页，检查真实 WebView2 初始化、Cookie 与存储共享、页面状态隔离、布局切换、暂停恢复、弹窗通信、快捷键冲突和配置持久化。它不会代替第三方平台的真实账号登录验证。

核心无第三方依赖；UI 唯一 NuGet 依赖是 Microsoft.Web.WebView2。自动化测试和截图位于 `artifacts\smoke-*\`，构建产物位于 `artifacts\release\`。

## 源码结构

- `src/Bingyu.Core/`：标签 / 分屏状态、网址校验、持久化。
- `src/Bingyu.App/`：WPF 界面、网页容器、登录弹窗、托盘、全局快捷键。
- `tests/Bingyu.Core.Tests/`：核心行为与随机序列测试。
- `scripts/`：构建、打包与桌面集成检查。

当前版本：0.1.13，Windows x64。未包含自动更新、自动启动、云同步或代码签名。
